# Support

This is an open-source Skill maintained without a response-time or support SLA.

Choose the route that matches the request:

- **Usage questions and adoption stories:** use [GitHub Discussions](https://github.com/zltstl888/apex-tool-evaluator/discussions).
- **Public evaluation proposals:** use the [Evaluation Request](https://github.com/zltstl888/apex-tool-evaluator/issues/new?template=evaluation-request.yml) form.
- **Reproducible Skill behavior:** use the [Behavior Report](https://github.com/zltstl888/apex-tool-evaluator/issues/new?template=behavior-report.yml) form.
- **Validator, CI, or package problems:** use the [Validator Report](https://github.com/zltstl888/apex-tool-evaluator/issues/new?template=validator-report.yml) form.
- **Security vulnerabilities:** follow [`SECURITY.md`](SECURITY.md) and use [private vulnerability reporting](https://github.com/zltstl888/apex-tool-evaluator/security/advisories/new).

Do not submit credentials, customer data, private tool inventories, private paths, or confidential logs. A verdict or maintainer reply does not authorize installation, payment, OAuth access, production change, or handling of regulated data.
