# Changelog

All notable changes are recorded here. This project follows semantic versioning.

## 0.1.3 - 2026-08-29

- Add a public evaluation guide connecting behavior fixtures, balanced trigger fixtures, and the evidence-backed tool-evaluation example.
- Add 20 realistic trigger fixtures with a 10:10 should-trigger and should-not-trigger balance.
- Record the versioned Social Preview asset, dimensions, and checksum for reproducible sharing.
- Require evaluation documentation, trigger coverage, release-version consistency, and the `.skill` release asset in validation.
- Expand validator regression coverage and limit push CI runs to the `main` branch.
- Keep the core evaluation contract, Apache-2.0 license, provenance record, and safety boundaries unchanged.

## 0.1.2 - 2026-08-29

- Add a dated, evidence-backed public evaluation of the `skills` CLI.
- Make normal, edge, and negative eval coverage machine-checkable.
- Add citation, conduct, support, and pull-request community files.
- Carry the pain-led README and participation paths into a tagged release.
- Add release checksum guidance without changing the core evaluation contract.

## 0.1.1 - 2026-08-25

- Add a one-command tagged installation path.
- Add compact normal, edge, and out-of-scope examples.
- Improve the README decision flow and contribution entry points.
- Add structured issue templates for behavior reports and evaluation requests.

## 0.1.0 - 2026-08-25

- Publish the first public APEX AI Agent Skill.
- Add evidence-led verdicts, risk gates, scorecard, and bounded test planning.
- Add proportional intake, standard, and full evaluation depth.
- Add normal, edge, and negative eval cases.
- Add Agent Skills reference validation, a limited public-boundary linter, negative regression tests, CI, provenance, and third-party notices.
